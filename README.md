# CMCB_Practical_Course_Vertex_Modelling

This git repository contains the code needed to run a 2D vertex model based simulation. If you want to run locally in e.g. a jupyter notebook, download the .zip file of the entire repository and delete the first cell within the main notebook, 
otherwise visit the URL 
https://colab.research.google.com/github/IanEstabrook/CMCB_Practical_Course_Vertex_Modelling/blob/main/vertex_model_main_final.ipynb

which will open the main notebook in a google colab environment. Run the first cell if using the above link, otherwise ignore it when running locally.
